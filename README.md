# Conversor de Moedas

App criado com React Native + Expo para converter valores entre moedas em tempo real.

## Como executar

```bash
npm install
npm start
```

Depois, escolha a opção web no terminal do Expo ou abra o app em um dispositivo físico.

## Funcionalidades

- Conversão entre moedas populares
- Consulta de taxa em tempo real via API pública
- Seleção de moeda de origem e destino
- Botão para inverter moedas
- Interface moderna e responsiva
